Estoy en la fase final del Grado en Ingeniería Informática del Software en la
Universidad de Sevilla, con el Trabajo de Fin de Grado y las prácticas pendientes
para completar mis estudios.

Busco una oportunidad de prácticas o una posición junior relacionada con la
ingeniería del software, donde pueda seguir desarrollándome y aportar los
conocimientos adquiridos durante el grado. En mis proyectos académicos he
trabajado en aplicaciones web, plataformas SaaS, APIs REST, bases de datos,

utilizando Git y GitHub.

## Proyectos destacados

### [NexUS · 2025–2026](https://github.com/Javiergutpas/ISPP-Nexus)

Plataforma SaaS multitenant para la gestión de residencias universitarias,
con herramientas de comunicación, reservas, analítica y matching asistido por IA.

**Tecnologías:** React, TypeScript, Vite, Django, Django REST Framework,
PostgreSQL, Redis, Celery, Docker y Nginx.

### [Otelo · 2025–2026](https://github.com/Javiergutpas/IA-Otelo)

Agente inteligente para jugar al juego de estrategia Otelo mediante Monte Carlo
Tree Search (MCTS), UCT y redes neuronales convolucionales.

**Tecnologías:** Python, NumPy, Pandas, scikit-learn, TensorFlow y Keras.

### [Vians Fashion · 2025–2026](https://github.com/Javiergutpas/PGPI-TiendaVirtual)

Tienda virtual desarrollada con Django para la personalización de prendas,
gestión de pedidos, pagos online y generación de facturas.

**Tecnologías:** Python, Django, SQLite, JavaScript, HTML, CSS, Bootstrap,
Stripe y ReportLab.

### [Petris · 2024–2025](https://github.com/Javiergutpas/DP1-Petris)

Aplicación web full stack para partidas online entre dos jugadores, con
autenticación, estadísticas, rankings y documentación de API.

**Tecnologías:** Java, Spring Boot, React, JavaScript, H2, Maven, Docker,
JUnit y REST APIs.
